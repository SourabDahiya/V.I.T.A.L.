📐 How Accuracy Is Measured

1. Edge Jaccard (Tracking Score)

Measures how accurately cell movements between frames are connected, with a penalty for predicting phantom cells:

Edge Jaccard = [TP / (TP + FP + FN)] × min(1.0, N_ground_truth / N_predicted)

Cells are matched to ground truth if their 3D physical position is within 7.0 µm.

2. Division Jaccard (Mitosis Score)

Measures how accurately cell splitting events (mitosis) are discovered:

Division Jaccard = TP_div / (TP_div + FP_div + FN_div)

Counted as a match (TP) only when the parent cell and both daughter cells are correctly identified within 1.5 to 16.0 µm.
